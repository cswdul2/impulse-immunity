2. 시험자 인터뷰 (Failure Mode 분석)

테스트 진행 시 관측된 구체적인 실패 양상. 시간 경과(열적 요인 또는 전하 축적)가 주요 변수.

  • Short-term (1분): ±3kV 강도에서도 OK (내성 있음)
  • Long-term (10분): 10분 ±2kV 강도에서 문제 발생
  • 특이사항: I0 (누설전류 등) 측정, 8가지 결선의 impulse 시험에서 멈추거나 오동작하는 경향 확인
